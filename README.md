本站采用零构建静态架构，以早年 **n-buna（拿不拿）** 与早期 **Yorushika** 实体唱片美学为视觉灵感，完整保留原站全部算法笔记、日常文章、头像与友链，并新增「十四幕盛夏光影美术馆」策展体验。

## 十四幕 · 盛夏光影美术馆与设计亮点

- **四幕时间线策展（`#/gallery` & 首页 35mm 胶片长卷）**：按 *ACT I 朝露与昼青 → ACT II 无人站与日暮 → ACT III 透明哀歌与终电 → ACT IV 黎明与萤火* 串联 `P01`–`P14` 十四幅作品。
- **双模式三连电车车窗**：首页右侧车窗支持在「官方封面 2014–2016」与「十四幕精选 P01 / P05 / P14」之间一键切换。
- **暗房策展灯箱 2.0**：支持缩略图快速跳转、画师铭牌与 Pixiv/X 原作直达链接、采样色卡点击复制与右下角 BGM 曲目联动。
- **可替换无图槽位**：暂缺原图的 4 幕（`p02-mujin-eki.svg`、`p03-tomisaka.svg`、`p10-meryu.svg`、`p12-uncredited.svg`）保存在 `images/exhibition/` 下；日后找到原截图或原图后，只需用同文件名覆盖或改 `js/config.js` 里的 `image` 路径即可无缝替换。

## 如何发布新文章

1. 在 `posts/` 文件夹中新建一个 `.md` 文件（支持 Markdown 代码块与 `$...$` LaTeX 数学公式）。
2. 在 `js/data.js` 的 `BLOG_POSTS` 数组最前面添加一条文章登记。
3. 提交并推送到 `main` 分支，GitHub Pages 原生分支构建会在约 30 秒内自动部署上线。
